Full-stack AI system that automates job discovery, resume analysis, and application tracking using LLM-powered workflows.

## Overview

The AI Job Search Agent streamlines the job search process by combining real job listings with AI-driven evaluation and personalization.

It helps users:
- Discover relevant job opportunities  
- Understand skill gaps based on job descriptions  
- Generate tailored resumes and cover letters  
- Track applications in a centralized dashboard  

---

## How It Works

- Uses JSearch API (RapidAPI) to pull real job listings from platforms like LinkedIn, Indeed, and Glassdoor  
- Applies Claude API (LLM) to analyze job descriptions and resumes  
- Runs structured AI workflows for job-fit scoring and ranking  
- Generates personalized cover letters based on user profiles and target roles  
- Stores and organizes applications in a tracking dashboard  

---

## Key Features

- Real-time job search using live listings (JSearch API)  
- AI-powered job-fit scoring based on skills and experience  
- Resume gap analysis with actionable improvement suggestions  
- Automated cover letter generation tailored to each role  
- Application tracking dashboard for managing job pipelines in one place

## Tech Stack

- JavaScript (Frontend + Backend logic)  
- HTML / CSS  
- Claude API (LLM reasoning and generation)  
- JSearch API (job listings data source)  
- Serverless functions (Vercel deployment)  

---

## Why I Built This

I built this project to automate and improve the modern job search process, which is often fragmented across multiple platforms and requires repetitive manual effort.

The goal was to simulate parts of a recruiter’s workflow including job matching, screening, and candidate evaluation and turn it into a single AI-powered system.
